? HOW TO USE
STEP 01

기본 조건 선택

COLOR, MAIN STYLE, HEAD PIECE, COMPLEXITY, ANIMAL을 고른다. OTHER에는 ribbons, horns처럼 기본 선택지에 없는 추가 태그만 직접 입력한다.

STEP 02

◇ 버튼으로 잠금

옆의 ◇를 누르면 ◆로 바뀌며 해당 선택 항목이 잠긴다. SHUFFLE을 눌러도 잠긴 항목은 유지된다.

STEP 03

PRINT OUTFIT

호환되는 스타일·상의·하의·신발·액세서리를 조합한 뒤, 출력구가 작동하며 프롬프트 종이가 단계적으로 실제 인쇄되듯 내려온다.

STEP 04

결과 사용

COPY로 바로 복사하거나 SAVE .TXT로 저장. REPRINT는 현재 설정을 유지한 채 새 조합을 다시 출력한다.

TIP. 색상 이름은 맨 앞에 한 번만 출력된다. ANIMAL의 Other...를 선택하면 직접 동물 이름을 입력할 수 있다. OTHER에는 wings, ribbons, chains처럼 기본 선택지에 없는 영어 태그를 쉼표로 추가할 수 있다.
